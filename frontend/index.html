def sort_list(nums):
    """
    Sorts a list of integers.
    
    Args:
        nums: The list to sort.
    
    Returns:
        The sorted list.
    """
    
    # Use the built-in sort() method to sort the list.
    nums.sort()
    
    return nums

Example Usage:

# Create a list of integers to sort.
nums = [5, 2, 8, 3, 1]

# Sort the list.
sorted_nums = sort_list(nums)

# Print the sorted list.
print(sorted_nums)

Output:

[1, 2, 3, 5, 8]

Explanation:

  1. The `sort_list()` function takes a list of integers as input.
  2. It uses the `sort()` method to sort the list in ascending order.
  3. The function returns the sorted list.
